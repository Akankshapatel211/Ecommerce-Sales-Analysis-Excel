# E-Commerce Sales Analysis -- Excel

## Project Overview

This project analyzes e-commerce sales data using Microsoft Excel. The
objective is to clean and analyze sales data, calculate key business
metrics, and build an interactive dashboard to understand sales
performance, profitability, regional performance, category performance,
and monthly sales trends.

## Tools Used

-   Microsoft Excel
-   Excel Tables
-   PivotTables
-   PivotCharts
-   Slicers
-   Conditional Formatting

## Excel Skills Used

-   Data cleaning and validation
-   Sorting and filtering
-   IF, AND, and IFERROR
-   SUMIF and SUMIFS
-   COUNTIF and COUNTIFS
-   AVERAGEIF and AVERAGEIFS
-   XLOOKUP
-   VLOOKUP
-   INDEX-MATCH
-   Text functions: TRIM, UPPER, LOWER, LEN, LEFT, RIGHT, MID, CONCAT
-   Date functions: YEAR, MONTH, TEXT
-   Calculated columns
-   PivotTables and PivotCharts
-   Interactive slicers
-   Dashboard creation

## Key Calculations

-   Profit
-   Profit Margin
-   Year, Month, and Quarter
-   Sales Category
-   Profit Status
-   Large Order classification

## Dashboard KPIs

-   Total Sales
-   Total Profit
-   Total Orders
-   Profit Margin

## Analysis Performed

-   Sales by Region
-   Sales by Category
-   Profit by Region
-   Sales by Product
-   Monthly Sales Trend
-   Orders by Category
-   Top Products by Sales
-   Interactive analysis using Region, Category, and Order Status
    slicers

## Project Objective

The purpose of this project is to demonstrate practical Excel skills
used in Data Analyst roles, including data cleaning, business
calculations, lookup functions, aggregation, PivotTable analysis,
visualization, and interactive dashboard development.
